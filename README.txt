# AMC Transportergroep – eerste versie

Deze versie is een statische demo die direct op GitHub Pages kan worden gezet.

Inbegrepen:
- Naam invullen
- Datum kiezen
- Locatie-keuzelijst: AH, PK, BUS, PW, WZ, MDW, ST, TOTAL
- Alleen de afgesproken vaste tijdslots
- Aanvraag indienen
- Beheer: accepteren/weigeren
- Meerdere bussen
- Maximaal 8 personen per bus
- Personen aan een bus toewijzen
- Vrije/bezette plaatsen tonen

Belangrijk:
Deze demo gebruikt localStorage. Daardoor zijn gegevens alleen zichtbaar in dezelfde browser/apparaat. Voor echte gebruikers, een veilige beheerlogin, gedeelde database en WhatsApp-meldingen moet een backend worden gekoppeld. Dat is de volgende technische stap.
